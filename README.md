# quarto — 4目並べの対戦ボードゲーム

4つの属性が揃ったら勝ちの対戦パズル

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/quarto/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

4×4 の盤と 16 個のコマ。コマは 4 つの属性がそれぞれ 2 択（色・高さ・形・中）で、16 個すべて違う組み合わせ。

1. 相手に渡すコマを、下のコマ置き場からタップで選ぶ。
2. 渡されたコマを、空いているマスにタップで置く。
3. 縦・横・斜めのどれか 1 列の 4 個が、ある属性を 1 つでも共通に持てば、置いた人の勝ち。16 マス埋まって揃わなければ引き分け。

「CPU と対戦」と「2人で対戦（1台で交互）」から選べる。試作のため効果音・設定・共有の演出・記録はなし。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```
